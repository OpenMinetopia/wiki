Op deze pagina staan alle commando's van OpenMinetopia, gegroepeerd per module. Onderaan vind je een lijst met alle permissies.

## Zo lees je de tabellen

- `<naam>` is een verplicht argument, `[naam]` is optioneel.
- Staat er "Geen" bij de permissie, dan mag iedereen het commando gebruiken.
- Een commando zonder argumenten dat alleen een helplijst toont, werkt ook als `<commando> help`. De helplijst toont alleen subcommando's waar je permissie voor hebt.
- De meeste commando's werken alleen in-game. Deze werken ook vanuit de console: `/omt reload`, `/omt help`, `/rekening create`, `/rekening info`, `/rekening freeze`, `/rekening setbalance`, `/rekening adduser`, `/rekening removeuser`, `/currency purge-unused`, de valuta-commando's met een speler als argument, `/color add`, `/fitheid togglereset`, `/prefix add`, `/prefix remove` en `/112`. Ook de helplijsten (`<commando> help`) werken vanuit de console.

<Note>
Commando's bestaan alleen als hun module aan staat. Zet je een module uit met `disabled-modules` in `config.yml`, dan verdwijnen ook de commando's van die module. Zie [Configuratie](/plugin/configuratie).
</Note>

## Hoe permissies werken

OpenMinetopia registreert zijn permissies nergens. `paper-plugin.yml` bevat geen permissies en de plugin maakt ook in de code geen permissies aan. Daardoor geldt de standaardregel van Bukkit voor onbekende permissies: alleen OP's hebben ze. De console heeft altijd alle permissies.

Wil je een gewone speler een commando geven, dan geef je de permissie met een permissieplugin zoals LuckPerms.

Een commando met permissie "Geen" werkt voor iedereen. Sommige van die commando's controleren in de code nog wel iets, bijvoorbeeld of je eigenaar bent van een plot. Dat staat dan in de tabel.

## Algemeen

| Commando | Wat het doet | Permissie |
|---|---|---|
| `/omt` | Toont de versie en de makers van de plugin. | Geen |
| `/omt reload` | Herlaadt `config.yml`, `messages.yml`, `levelcheck.yml`, `colors.yml`, `fitness.yml`, `banking.yml`, `plotcalculate.yml`, `books.yml`, `labymod.yml` en de items. Bestanden van uitgeschakelde modules worden overgeslagen. | `openminetopia.reload` |
| `/omt help [pagina]` | Toont de commando's van de plugin, 10 per pagina. De valuta-commando's staan er niet in. | `openminetopia.help` |

Aliassen: `/openminetopia`, `/minetopia`, `/sdb`.

## Valuta

Zie [Valuta](/plugin/modules/valuta).

| Commando | Wat het doet | Permissie |
|---|---|---|
| `/currency purge-unused` | Verwijdert alle valuta uit de database die niet meer in `currencies.yml` staan. Typ het commando binnen 20 seconden een tweede keer om te bevestigen. | `openminetopia.currency.purge` |

Alias: `/currencies`.

Elke valuta in `currencies.yml` krijgt een eigen commando. De naam van het commando is de ID van de valuta, en de `aliases` uit `currencies.yml` werken ook. In de standaardconfig is dat `/graycoin` met alias `/gc`. Hieronder staat `<valuta>` voor die ID.

| Commando | Wat het doet | Permissie |
|---|---|---|
| `/<valuta>` | Toont je eigen saldo van deze valuta. | Geen |
| `/<valuta> help` | Toont de helplijst. Zonder permissie zie je niets. | `openminetopia.currency.<valuta>` |
| `/<valuta> <speler>` | Toont het saldo van een andere speler. | `openminetopia.currency.info.<valuta>` |
| `/<valuta> set <speler> <hoeveelheid>` | Zet het saldo van een speler. | `openminetopia.currency.set.<valuta>` |
| `/<valuta> add <speler> <hoeveelheid>` | Telt een hoeveelheid op bij het saldo van een speler. | `openminetopia.currency.add.<valuta>` |
| `/<valuta> remove <speler> <hoeveelheid>` | Haalt een hoeveelheid van het saldo van een speler af. | `openminetopia.currency.remove.<valuta>` |

De speler moet al eens op de server zijn geweest. Elke andere combinatie van argumenten toont de helplijst.

| Commando | Wat het doet | Permissie |

| `/lock removegroup <groep>` | Haalt de toegang van een groep weg. | `openminetopia.lock.group` |
| `/unlock` | Haalt het slot van het blok waar je naar kijkt. | Geen, `openminetopia.unlock` om het plot-eigenaarschap over te slaan |
| `/sleutel` | Toont hoe je het commando gebruikt. | `openminetopia.key` |

Aliassen: `/sleutel` is ook `/key`. `/sleutel alle` is ook `/sleutel all` en `/sleutel master`. `/sleutel slot` is ook `/sleutel lock`.

| `openminetopia.unlock` | `/unlock` gebruiken op blokken buiten je eigen plot. |

| `openminetopia.police` | Noodmeldingen van `/112` ontvangen. |

| `openminetopia.walkietalkie` | De portofoon gebruiken, berichten van de portofoon ontvangen en in de contactenlijst van de portofoon staan. |
| `openminetopia.staffchat` | Staffchat-berichten ontvangen en via de chat naar de staffchat praten. |
| `openminetopia.admintool` | Het AdminTool-item gebruiken: linksklikken voor je eigen menu, rechtsklikken op een speler voor zijn menu. |
