OpenMinetopia bewaart al zijn instellingen in de map `plugins/OpenMinetopia`. Op deze pagina lees je welke bestanden daar staan, wat elke instelling in `config.yml` doet en hoe je wijzigingen laadt.

## De datamap

De plugin maakt de bestanden zelf aan bij de eerste start. Een modulebestand verschijnt alleen als die module aan staat.

| Bestand | Gemaakt door | Uitleg |
|---|---|---|
| `config.yml` | `DefaultConfiguration` | Algemene instellingen. Staat hieronder. |
| `messages.yml` | `MessageConfiguration` | Alle berichten van de plugin. Zie [Berichten](#berichten-messagesyml). |
| `levelcheck.yml` | `LevelCheckConfiguration` (module `player`) | [Levels](/plugin/modules/levels) |
| `banking.yml` | `BankingConfiguration` (module `banking`) | [Bankieren](/plugin/modules/bankieren) |
| `currencies.yml` | `CurrencyConfiguration` (module `currencies`) | [Valuta](/plugin/modules/valuta) |
| `fitness.yml` | `FitnessConfiguration` (module `fitness`) | [Fitheid](/plugin/modules/fitheid) |
| `colors.yml` | `ColorsConfiguration` (module `color`) | [Kleuren](/plugin/modules/kleuren) |
| `plotcalculate.yml` | `PlotCalculateConfiguration` (module `plots`) | [Plots](/plugin/modules/plots) |
| `books.yml` | `BooksConfiguration` (module `books`) | [Boeken](/plugin/modules/boeken) |
| `labymod.yml` | `LabymodConfiguration` (module `labymod`) | [LabyMod](/plugin/modules/labymod) |
| `items/` | `ItemsModule` | Map met `categories.yml` en de itembestanden. Zie [Items](/plugin/modules/items). |
| `database.db` | `SQLiteAdapter` | De database, alleen bij `database.type: sqlite`. |

De plugin vult ontbrekende sleutels in `config.yml` zelf aan met de standaardwaarde. Dat gebeurt bij elke start en bij `/openminetopia reload`. Haal je een sleutel weg, dan staat hij er de volgende keer dus weer. Een lege tekstlijst, zoals `scoreboard.lines: []` of `plot.commands-on-create: []`, telt ook als ontbrekend: de plugin zet dan de standaardlijst terug.

<Warning>
  De plugin schrijft `config.yml` ook zelf weg, bijvoorbeeld bij `/head add` en `/head remove`. Bewerk je het bestand terwijl de server draait, laad je wijzigingen dan meteen met `/openminetopia reload`. Anders kan de plugin ze overschrijven.
</Warning>

## config.yml

Hieronder staan alle sleutels per onderdeel, met de standaardwaarde die de plugin wegschrijft.

Teksten gebruiken [MiniMessage](https://docs.advntr.dev/minimessage/format.html), zoals `<gray>` en `<gold>`. In de chat-opmaak, het scoreboard en de actiebalk kun je de placeholders van OpenMinetopia gebruiken, zoals `<level>` en `<world_color>`. Die staan op [Placeholders](/plugin/placeholders).

### Statistieken

```yaml
metrics:
  enabled: true
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `metrics.enabled` | boolean | `true` | Stuurt gebruiksstatistieken naar bStats, waaronder het type database dat je gebruikt. |

### Database

```yaml
database:
  type: sqlite
  host: localhost
  port: 3306
  name: openminetopia
  username: root
  password: password
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `database.type` | tekst | `sqlite` | `sqlite` of `mysql`. Hoofdletters maken niet uit. |
| `database.host` | tekst | `localhost` | Adres van de MySQL-server. |
| `database.port` | getal | `3306` | Poort van de MySQL-server. |
| `database.name` | tekst | `openminetopia` | Naam van de database. |
| `database.username` | tekst | `root` | Gebruikersnaam voor de database. |
| `database.password` | tekst | `password` | Wachtwoord voor de database. |

- `sqlite` bewaart alles in het bestand `database.db` in de datamap. De andere database-sleutels gebruikt de plugin dan niet.
- `mysql` verbindt met `host`, `port`, `name`, `username` en `password`. Gebruik dit voor een MySQL- of MariaDB-server.
- Lukt de verbinding niet, dan schakelt de plugin zichzelf uit en zie je de fout in de console.
- Herkent de plugin het type niet, dan gebruikt hij SQLite en logt hij een foutmelding.

<Warning>
  De code kent ook het type `mongo`, maar dat is niet geïmplementeerd. Met `type: mongo` start de database niet.
</Warning>

### REST API

```yaml
rest-api:
  enabled: false
  host: 127.0.0.1
  port: 4567
  api-key: CHANGE-ME
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `rest-api.enabled` | boolean | `false` | Start de ingebouwde webserver van de REST API. |
| `rest-api.host` | tekst | `127.0.0.1` | Adres waarop de API luistert. |
| `rest-api.port` | getal | `4567` | Poort waarop de API luistert. |
| `rest-api.api-key` | tekst | `CHANGE-ME` | Sleutel die elk verzoek moet meesturen in de header `X-API-Key`. Verander deze altijd. |

Meer hierover op [REST API](/plugin/rest-api).

### Portaal

```yaml
portal:
  enabled: false
  url: portal.openminetopia.nl
  token: CHANGE-ME
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `portal.enabled` | boolean | `false` | Zet het commando `/koppel` (alias `/link`) aan. |
| `portal.url` | tekst | `portal.openminetopia.nl` | Adres van het portaal. |
| `portal.token` | tekst | `CHANGE-ME` | Token van je server in het portaal. De plugin stuurt het mee in de header `X-API-Key`. |

De plugin zet `/api` achter `portal.url`. Begint het adres met `http://` of `https://`, dan gebruikt de plugin het zoals het er staat. Staat er alleen een domeinnaam, dan zet de plugin er `https://` voor, of `http://` als de naam op `.test` eindigt (voor lokaal testen). Meer op [Koppelen met de plugin](/portaal/koppelen).

Hoe je je server koppelt, lees je op [Server koppelen](/portaal/koppelen).

### Standaardwaarden voor spelers

```yaml
  prefix: Zwerver
  prefix-color: <gray>
  level: 1
  level-color: <gray>
  name-color: <white>
  chat-color: <white>
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `default.prefix` | tekst | `Zwerver` | Prefix van een speler zonder actieve prefix. |
| `default.prefix-color` | tekst | `<gray>` | Standaardkleur van de prefix. |
| `default.level` | getal | `1` | Laagste level dat de levelberekening geeft. |

Draagt een speler een bivakmuts, dan toont de chat deze standaardwaarden in plaats van zijn eigen prefix, level en kleuren. Zie ook [Prefixen](/plugin/modules/prefixen), [Kleuren](/plugin/modules/kleuren) en [Levels](/plugin/modules/levels).

De opmaak werkt alleen als de speler in een plaats staat. Meer op [Chat](/plugin/modules/chat).

### Detectiepoortjes

```yaml
detection-gate:
  enabled: true
  blocks:
    replacement-range: 5
    pressure-plate-type: LIGHT_WEIGHTED_PRESSURE_PLATE
    activation-block: IRON_BLOCK
  cooldown: 3
  flagged-materials:
  - type: SUGAR
    custom-model-data: -1
  # ... en de andere items uit de tabel hieronder
  flag-blocks:
    safe:
      BLACK_WOOL: LIME_WOOL
      BLACK_CONCRETE: LIME_CONCRETE
      BLACK_TERRACOTTA: LIME_TERRACOTTA
```

| Sleutel | Type | Standaard | Wat het doet |

| `detection-gate.enabled` | boolean | `true` | Zet detectiepoortjes aan. |

| `detection-gate.blocks.pressure-plate-type` | materiaal | `LIGHT_WEIGHTED_PRESSURE_PLATE` | Drukplaat die het poortje activeert. |

| `detection-gate.cooldown` | getal | `3` | Seconden voordat het poortje terugspringt en weer werkt. |
| `detection-gate.flagged-materials` | itemlijst | 12 items | Items die het poortje laten afgaan. |
| `detection-gate.flag-blocks.safe` | blok: blok | zie hierboven | Welke blokken in welk blok veranderen als er niets gevonden is. |
| `detection-gate.flag-blocks.flagged` | blok: blok | zie hierboven | Welke blokken in welk blok veranderen als er wel iets gevonden is. |

Standaard staan in `flagged-materials`: `SUGAR`, `IRON_HOE`, `STICK`, `WOODEN_SWORD`, `SPIDER_EYE`, `FERMENTED_SPIDER_EYE`, `SNOWBALL`, `ARROW`, `BOW`, `ROTTEN_FLESH`, `STONE_HOE` en `POISONOUS_POTATO`. Elk item staat erin met `custom-model-data: -1`.

</Warning>

#### Items en effecten invullen

Een **itemlijst** is een lijst met items. Per item kun je deze velden invullen:

| Veld | Wat het doet |
|---|---|
| `type` | Het materiaal, bijvoorbeeld `GRAY_DYE`. Verplicht. |
| `custom-model-data` | Custom model data. `-1` betekent: niet gebruiken. |
| `item-model` | Item model in de vorm `namespace:sleutel`. Optioneel. |
| `damage` | Schade-waarde. Optioneel. |

Bij elk item schrijft de plugin zelf ook `damage: -1` en `item-model: ''` in `config.yml`. `-1` en een lege tekst betekenen: niet gebruiken. In de voorbeelden op deze pagina staan die twee regels niet.

Bij **effecten** is de sleutel de naam van een Minecraft-effect, zoals `blindness` of `slowness`. Onder elk effect staat `amplifier` (de sterkte, `0` is niveau 1). Het veld `duration` gebruikt de plugin niet. Bij pepperspray en taser bepaalt `effects-duration` hoe lang de effecten duren. Bij handboeien en nachtkijker duren ze zolang iemand geboeid is of de nachtkijker op heeft.

### PvP

```yaml
pvp:
  enabled: true
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `pvp.enabled` | boolean | `true` | Zet de PvP-regels van OpenMinetopia aan. |
| `pvp.items` | lijst | leeg | Items waarmee spelers elkaar mogen aanvallen, met een bericht voor aanvaller en slachtoffer. |

Met `pvp.enabled: true` mogen spelers in een plaats elkaar alleen aanvallen met een item uit `pvp.items`. Slaan met de hand of met een item dat er niet in staat, wordt geblokkeerd. Dat geldt ook voor sneeuwballen en pijlen, tenzij `SNOWBALL` of `ARROW` in de lijst staat.

Bij een nieuwe installatie is `pvp.items` leeg. De jar bevat wel een voorbeeldlijst, maar die kopieert de plugin niet. Wil je hem gebruiken, zet hem dan zelf in je `config.yml`:

```yaml
pvp:
  enabled: true
  items:
    - item:
        type: STICK
      attacker-message: "<red>Je hebt <dark_red><victim> <red>geslagen met jouw knuppel"
      victim-message: "<red>Je bent geslagen met een knuppel!"
    - item:
        type: FERMENTED_SPIDER_EYE
      attacker-message: "<red>Je hebt <dark_red><victim> <red>geslagen met jouw wapenstok"
      victim-message: "<red>Je bent geslagen met een wapenstok!"
    - item:
        type: STONE_AXE
```

### Sleutels

```yaml
key:
  type: PAPER
  custom-model-data: -1
  item-model: minecraft:custom/items/sleutel
  name: <gold>Sleutel
  lore:
  - <gray>Een sleutel om sloten mee te openen.
  lore-master: '<gray>Past op: <green>alle sloten'
  lore-blocks: '<gray>Vergrendelde blokken: <white><amount>'
  lore-plot: '<gray>Plot: <white><plot>'
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `key.type` | materiaal | `PAPER` | Materiaal van de sleutel. Bij een ongeldig materiaal gebruikt de plugin `PAPER`. |
| `key.custom-model-data` | getal | `-1` | Custom model data. `-1` betekent: niet gebruiken. |
| `key.item-model` | tekst | `minecraft:custom/items/sleutel` | Item model van de sleutel. Leeg betekent: niet gebruiken. |
| `key.name` | tekst | `<gold>Sleutel` | Naam van de sleutel. |
| `key.lore` | lijst | zie hierboven | Vaste regels onder de naam. |
| `key.lore-master` | tekst | zie hierboven | Regel op een sleutel die op alle sloten past. |
| `key.lore-blocks` | tekst | zie hierboven | Regel met het aantal vergrendelde blokken. `<amount>` is dat aantal. |
| `key.lore-plot` | tekst | zie hierboven | Regel per plot waar de sleutel op past. `<plot>` is de plot. |

### Modules uitzetten

```yaml
disabled-modules: []
```

| Sleutel | Type | Standaard | Wat het doet |
|---|---|---|---|
| `disabled-modules` | lijst | leeg | Modules die de plugin niet laadt. |

Een modulenaam is de naam van de map van die module in de broncode. Hoofdletters maken niet uit. Deze namen kun je gebruiken:

`actionbar`, `backpack`, `banking`, `books`, `chat`, `color`, `core`, `currencies`, `detectiongates`, `fitness`, `items`, `labymod`, `lock`, `misc`, `places`, `plots`, `police`, `portal`, `prefix`, `restapi`, `scoreboard`, `skript`, `staff`, `teleporter`, `time`, `transactions`

`player` en `data` kun je niet uitzetten. De plugin negeert die namen.

```yaml
disabled-modules:
  - labymod
  - skript
```

<Warning>
  Niet elke module kan zonder problemen uit. Sommige onderdelen vragen andere modules direct op. Zo gebruikt de opmaak van chat, scoreboard en actiebalk altijd `banking` en `currencies`, en de chat ook `police`. Zet je zo'n module uit, dan kun je fouten in de console krijgen. Zet je `core` uit, dan verdwijnt ook `/openminetopia reload`.
</Warning>

## Berichten (messages.yml)

In `messages.yml` staan alle teksten die spelers van de plugin te zien krijgen. Elk bericht is één regel met een sleutel en een tekst:

```yaml
no_player_provided: "<red>Je moet een speler opgeven."
banking_account_created: "<gold>Je hebt de rekening</gold> <red><account_name></red> <gold>aangemaakt."
```

- Berichten gebruiken [MiniMessage](https://docs.advntr.dev/minimessage/format.html). Oude kleurcodes met `§` haalt de plugin weg.
- Woorden tussen `< >` die geen kleur zijn, zoals `<account_name>`, vult de plugin zelf in. Welke placeholders er zijn, verschilt per bericht. Kijk naar het bericht in het standaardbestand.
- Begin je een bericht met `[title]` of `[action]`, dan toont de plugin het als titel of in de actiebalk. Dit werkt niet bij elk bericht.
- Ontbreekt een sleutel, dan zet de plugin hem bij de volgende start of reload terug met de standaardtekst. Je eigen teksten blijven staan.
- Vindt de plugin een bericht niet, dan zie je in-game `<sleutel> was not found.`.

## Wijzigingen laden

Pas je een bestand aan, laad het dan opnieuw met:

| Commando | Wat het doet | Permissie |
|---|---|---|
| `/openminetopia reload` | Laadt de configuratie opnieuw. | `openminetopia.reload` |

Je kunt ook `/omt reload`, `/minetopia reload` of `/sdb reload` gebruiken.

Dit commando laadt opnieuw:

- `config.yml`, `messages.yml` en `levelcheck.yml`;
- `colors.yml`, `fitness.yml`, `banking.yml`, `plotcalculate.yml`, `books.yml` en `labymod.yml`, als die module aan staat;
- de map `items/`, als de module `items` aan staat.

`currencies.yml` laadt dit commando niet opnieuw. Herstart daarvoor de server.

Sommige instellingen in `config.yml` leest de plugin alleen bij het opstarten. Na een wijziging hierin moet je de server herstarten:

- `metrics.enabled`
- alles onder `database`
- `rest-api.enabled`, `rest-api.host` en `rest-api.port`
- `portal.enabled`
- `default.prefix-color`, `default.level-color`, `default.name-color` en `default.chat-color` (behalve in de chat van iemand met een bivakmuts)
- `scoreboard.enabled`
- `timesync.enabled`
- `disabled-modules`
